Method and limitations

  • The scanner retrieves the initial HTML and inspects it for known overlay product references.
  • It does not execute JavaScript or crawl linked pages.
  • It is not a WCAG conformance test or an accessibility audit.
  • Overlays injected at runtime may be missed.
  • Version information is best-effort and may be missing or wrong.
  • Sites that time out, block the request, or return an HTTP error have an unknown overlay status; they are not reported as clean.
  • The absence of a detected overlay is not proof that no overlay is present.
